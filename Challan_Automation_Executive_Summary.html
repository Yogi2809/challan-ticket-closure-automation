Challan Ticket Closure Automation

📅 May 2026 🚀 Deployed on GitHub Actions ⏰ Runs daily at 10:00 AM IST
Overview

A fully automated daily cron worker that reads a CSV report from Gmail, validates challan data against defined business rules, closes eligible Zendesk tickets, and sends a formatted Slack report with the results Excel sheet attached — all without any manual intervention.

# Column Condition Logic
1 UTF_CHALLANS Must be Blank No unresolved UTF challans
2 OPEN_CHALLANS Must be Blank No open challans pending
3 APPOINTMENT_ORDER_ID Must be Filled Valid appointment reference required
4 CLOSED_CHALLANS Must be Filled Closed challan count must exist
5 FIND_STATUS == RESOLVED Only fully resolved cases are closed
6 SOURCE_CODE == DEX Only DEX source tickets are processed
Ticket Closure Validation

TOTAL_CHALLANS ≠ CLOSED_CHALLANS Skip — counts don't match MISMATCH
API call fails / invalid values Log error, continue with next ERROR
What Was Built
  • Gmail IMAP reader — Fetches today's CSV attachment from the email subject "RAW - Challan OPS(VAS) closure_YYYY-MM-DD". Always picks the latest email in the thread.
  • Filter & validation engine — Applies all 6 filters, then validates TOTAL_CHALLANS == CLOSED_CHALLANS per row before any ticket is touched.
  • Zendesk API integration — PUT request per ticket with solved status, custom comment, and required custom field values. Handles SSL, timeouts, and API errors gracefully.
  • Excel output — Saves the filtered sheet with an UPDATED_RESULT column (SOLVED / MISMATCH / ERROR) for every processed row.
  • Slack report — Posts a summary (Total / Solved / Mismatch / Error counts + mismatch details) and uploads the Excel sheet directly to the channel.
  • GitHub Actions + cron-job.org — Workflow runs on workflow_dispatch. cron-job.org calls the GitHub API at exactly 4:30 AM UTC (10:00 AM IST) every day — replacing GitHub's unreliable native scheduler which was missing/delaying runs.
